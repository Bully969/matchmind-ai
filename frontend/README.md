# Frontend MatchMind AI

React + Vite, con dashboard dark responsive, navigazione inferiore su mobile e shell PWA per iPhone.

Dalla cartella `frontend` esegui `npm install` e `npm run dev`. L'API FastAPI si avvia separatamente sulla porta 8000. Configura `VITE_API_URL` per puntare al backend; non inserire chiavi provider nel frontend.

Molti elementi della UI (quote, trend, formazioni, eventi, rating e alcune statistiche) sono esempi visivi esplicitamente marcati. Non costituiscono dati live. Prima della produzione vanno sostituiti con provider autorizzati e copertura verificata.
